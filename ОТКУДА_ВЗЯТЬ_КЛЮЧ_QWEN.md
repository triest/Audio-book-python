# Откуда брать ключ для Qwen3-TTS (режим qwen_tts)

Этот режим — облачный синтез речи Alibaba (сервис **DashScope**,
модель Qwen3-TTS). Как и Yandex SpeechKit, он платный и требует
интернет на каждую главу. Ниже — как получить API-ключ.

Если платить за облако не хочется — локальный режим **Silero** в этой
же программе бесплатный и работает офлайн.

## Важно: старая консоль DashScope переехала

Раньше ключи выпускались прямо в консоли `dashscope.console.aliyun.com`,
но с 1 августа 2026 этот адрес отключён — при заходе показывается
сообщение "this service has been stopped... redirect to
bailian.console.aliyun.com". Управление ключами и моделями Alibaba
объединили в один продукт под названием **Bailian** (модельная
платформа/Model Studio) — сама программа-скрипт (`dashscope`, пакет,
который ставит `install.bat`) при этом не пострадала: API-адрес
(`dashscope.aliyuncs.com`) и формат ключа остались прежними, поменялся
только адрес консоли, где ключ получают. Шаги ниже — уже под новый
адрес.

## Шаг 1. Завести аккаунт Alibaba Cloud / Bailian

У Bailian есть ДВЕ разные консоли — китайская и международная (сразу на
английском, отдельным адресом, а не переключателем языка внутри одной
страницы):

* Китайская версия: https://bailian.console.aliyun.com
* **Международная версия (сразу на английском)**:
  https://modelstudio.console.aliyun.com — эту и открывайте, чтобы не
  искать переключатель языка внутри интерфейса, которого там просто
  нет как отдельной кнопки — это два разных сайта.

1. Откройте https://modelstudio.console.aliyun.com
2. Войдите под аккаунтом Alibaba Cloud или зарегистрируйте новый (нужен
   email и, как правило, привязка карты/платёжного метода — некоторые
   регионы дают бесплатный пробный лимит на старте, точные условия
   смотрите прямо в интерфейсе, они меняются).
3. Учтите: доступность и точные условия оплаты могут отличаться в
   зависимости от страны — если сервис недоступен в вашем регионе
   напрямую, это ограничение самого Alibaba Cloud, программа тут
   ничего поделать не может.

## Шаг 2. Получить API-ключ

1. Проще всего открыть сразу прямую ссылку на страницу ключей:
   https://modelstudio.console.aliyun.com/?tab=playground#/api-key
   (для китайской версии консоли она выглядит так:
   `https://bailian.console.aliyun.com/?tab=model#/api-key`). Если
   ссылка не сработает (адрес мог опять поменяться) — после входа
   ищите в меню слева пункт со словами **"API-KEY"** / **"API Key
   Management"**.
2. Если в списке уже есть ключ — можно просто скопировать его значком
   копирования рядом. Если ключей ещё нет — нажмите **"Create API
   Key"** ("Создать API Key").
3. В открывшемся окошке обычно просят выбрать тип аккаунта (оставьте
   основной аккаунт Alibaba Cloud) и рабочее пространство (оставьте
   "Default workspace"/"默认业务空间", которое выбрано по умолчанию), и
   права доступа — выберите "All"/"全部" (все), чтобы ключ точно
   подошёл для TTS. Нажмите **"Confirm"**/**"确定"**.
4. Скопируйте ключ сразу — он показывается один раз, как и у Yandex.
   Сохраните его в надёжном месте (менеджер паролей, защищённый файл).

## Шаг 3. Убедиться, что модель Qwen3-TTS вам доступна

В некоторых аккаунтах доступ к конкретным моделям нужно предварительно
включить ("activate"/"开通") в каталоге моделей Bailian — поищите там
**Qwen3-TTS** / **qwen3-tts-flash** и, если увидите кнопку вида
"Activate"/"Включить", нажмите её до первой попытки синтеза. Если
модель уже доступна сразу — этот шаг не нужен.

## Вставить ключ в программу

В графическом интерфейсе — блок **«Qwen3-TTS (режим qwen_tts)»**
справа, поле «API-ключ (DashScope)».

Из командной строки:

```
python3 fb2_reader.py book.fb2 --mode qwen_tts --qwen-api-key <ваш ключ> --qwen-voice Cherry --outdir audiobook
```

Ключ также можно один раз задать переменной окружения, чтобы не
вписывать каждый раз:

```
# Windows (cmd)
set DASHSCOPE_API_KEY=ваш_ключ

# Windows (PowerShell)
$env:DASHSCOPE_API_KEY = "ваш_ключ"
```

и запускать без флага `--qwen-api-key` — программа подхватит ключ из
переменной окружения `DASHSCOPE_API_KEY` сама (в графическом
интерфейсе поле тоже подставится автоматически из этой переменной,
если оно ещё не сохранено в настройках программы).

## Про эту интеграцию — важная оговорка

Поддержка Qwen3-TTS в программе написана по официальной документации
DashScope, но не проверялась на живом аккаунте (нет доступа к
интернету/ключу в среде разработки). Если при первой попытке озвучки
возникнет ошибка — пришлите мне её текст целиком (программа выводит
диагностику от сервера в журнал), это позволит быстро поправить разбор
ответа, если формат окажется другим, чем в документации.

## Частые проблемы

**401 / неверный ключ** — проверьте, что ключ скопирован полностью, без
лишних пробелов и переносов строк.

**403 / доступ запрещён / модель не активирована** — см. шаг 3 выше,
возможно модель Qwen3-TTS требует отдельной активации в вашем аккаунте.

**Лимит на длину запроса** — у DashScope довольно строгий лимит на
размер одного запроса (значительно меньше, чем у Yandex SpeechKit),
поэтому программа сама режет текст на короткие куски перед отправкой —
вручную ничего делать не нужно, но если увидите ошибку про длину
текста — сообщите мне, возможно куски нужно делать ещё короче.
