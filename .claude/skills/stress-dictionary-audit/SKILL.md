# Аудит словаря ударений

Словарь `forced_stress_words.json` (корень проекта) стоит выше silero-stress, шлюза и санитайзера:
записанная там форма читается ТОЧНО так. Поэтому «неверное ударение в книге» часто = ошибочная запись словаря.

## Порядок при жалобе на слово

1. `Grep` по слову (корень слова, без учёта регистра) в `*.py`, `*.json`: словарь, `<книга>.manual_stress_overrides.json`, `_PROSE_WORDS` в `fb2_reader.py`.
2. Если запись есть и ударение в ней неверное — править словарь, а не код. Менять ВСЕ формы слова разом
   (падежи, прилагательные «-ный/-ная…», производные вроде «транспортник») и добавить недостающие формы, которые встречаются в книге
   (`grep -o -i "[а-я]*корень[а-я]*" книга.fb2 | sort | uniq -c`).
3. Если записи нет — это ошибка модели: добавить формы в словарь, а для общего правила — `_PROSE_WORDS` (только слова с одним чтением).
4. Не уверены в норме — скажите об этом пользователю и спросите, а не угадывайте (слух решает пользователь).

## Что искать при общем проходе

- Ударение не на той гласной (бывали: `трансп+орт` вместо `тр+анспорт`, `сенс+ор` вместо `с+енсор`,
  `осн+овной` вместо `основн+ой`, `ткан+ей` вместо `тк+аней`). Записи словаря писались без прослушивания — проверять по орфоэпической норме.
- **Омографы удалять**: одиночные слова с двумя чтениями (душу, плена, броня и её падежи) — их решает silero-stress + шлюз по контексту;
  словарь не различает контекст. Фразы (ключ с пробелами) — не омографы, это контекстные правила, их оставлять.
- Формы слова должны быть согласованы (все падежи одним образом).

## Правка и проверка

Править через Python (`json.load`/`json.dump(ensure_ascii=False, indent=2)`), не вручную. Консоль Git Bash портит кириллицу в выводе —
для просмотра писать список в файл UTF-8 в scratchpad и читать `Read`.
Проверка: файл парсится; для одиночных слов `значение.replace('+','') == ключ` (с точностью до е/ё).
Озвучка в этой среде не запускается: ударение в аудио подтверждает только слух пользователя. Перезапуск не нужен;
хэш словаря входит в отпечаток главы, поэтому затронутые главы пересинтезируются (или «Re-run Synthesis» на вкладке «Словарь ударений»).
