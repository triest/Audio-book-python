# Цикл: жалоба/проверка → словарь → затронутые главы → пересинтез

Развивает `stress-chapter-review` (сухой прогон), `stress-dictionary-audit` (словарь) и `stress-book-run` (команда прогона). Здесь — порядок всей сессии и накопленные уроки (19 октября 2026, «Пепел победы»).

## 1. Жалоба с прослушивания
Пользователь пишет слово с заглавной на ударной гласной: «глАза», «заискрИлись», «мЕста» = ударение на эту гласную. «+обо, прет+ила» без пояснений = «оставь как есть» (уточни, если неясно).
1. Найди контекст в `pepel-pobedy.fb2` (`grep -a -o -i ".{40}фраза.{30}"`) и все словари: `forced_stress_words.json`, `pepel-pobedy.manual_stress_overrides.json`, `manual_stress_overrides.json`.
2. **Сначала ищи причину в записи словаря**, а не в модели: фразовые записи (часть создана «Анализом омографов книги») перебивают модель и бывают неверны в падеже. Так были неверны «места хватало» (род.п. ед.ч. = `м+еста`, не мн.ч. `мест+а`), «на подругу глаза» (вин.п. мн.ч. = `глаз+а`), «краешком глаза» (род.п. ед.ч. = `гл+аза`), «нимицем …» (`н+имицем`, ломало общую запись). Исправь ВСЕ однотипные записи с тем же словом (`grep` по корню), а не одну.
3. Нет записи, ошибается модель → одно чтение у слова: `forced_stress_words.json` (все нужные формы отдельными ключами); омограф → фраза в файле правок книги (слова те же, `+` по одному на слово, `значение.replace('+','') == ключ`).
4. Подмена произношения для опечаток книги: `pronunciation_substitutions.json` (`сосем` → `совс+ем`; только режим `silero_rest`).
5. Проверка: `stress_dry_run(текст, book_overrides_path="pepel-pobedy.manual_stress_overrides.json")` на 1–2 предложениях. Результат писать В ФАЙЛ (`open(..., "w", encoding="utf-8")`) и читать через `Read`/`cat`: при `python -I` консоль выдаёт cp1251-мусор, `PYTHONIOENCODING` не действует. Если скрипт молча ничего не вывел — убери `>/dev/null`, проверь `assert` (однажды молча упал из-за него).

## 2. «Проверь ещё главы N и M»
1. `.venv\Scripts\python.exe -I stress-chapter-review\dry_run_chapters.py <scratchpad>\dr N M` (номер главы = индекс как в `Глава N`; та же папка накапливает `words_seen`). `words_new.txt` лежит ОДНОЙ строкой — `wc -l` покажет 0, считай `wc -w`; читай через `Read`.
2. Фильтр: `.venv\Scripts\python.exe -I stress-listening-session\flag_vs_corpus.py <scratchpad>\dr N M` → `flag_new.txt` (расхождения с независимым корпусом + контекст) и `miss_new.txt` (слов нет в корпусе). Корпус хранит одно чтение омографа, не знает «ё» и ошибается на именах — это повод посмотреть контекст, не приговор. Просматривай оба файла целиком (Read), оценивай по смыслу и контексту.
3. Типовые ошибки цепочки, найденные таким способом (проверяй такие же в новых главах): падежные формы (модель ставит `+органов` вместо `орг+анов`: орган всегда `орг+ан…`; `год+а` в «три года» → `г+ода`; `сред+у` → `ср+еду`), `по-моему/твоему/своему` (модель ставит ударение на конец; верно `по-м+оему`), `подал`, `вступит/-ите`, `силясь`, `аки`, `должностей`, имена в косвенных падежах (`Уиль+яма`, `Ст+ивом`).
4. «Большой/большая» в форме `б+ольш…` ЧАСТО верна: это сравнительная степень («бо́льшая часть», «бо́льшие потери, чем…»). Смотри контекст, прежде чем «чинить». Так же `пр+авильно` — верно (пра́вильно).
5. Известное ограничение: у односложных слов ударение снимает `strip_monosyllable_stress` — запись `кое-чт+о` не работает («что», «кто» теряют метку); править надо код (`_MONO_KEEP_STRESS`), пока не просили — не трогать.
6. Не добавлять неуверенное. Имена и редкие слова (Шэннон, Феррет, Джулиус, Катрин, «кряжей», «секторов», «чужды») — отдельным коротким списком «под вопросом», пользователь решает на слух.
7. Итог пользователю: исправленное (слово → как), под вопросом, что пересинтезировать. Спросить «закоммитить и запушить?».

8. **Уроки глав 19–31 (19 октября 2026):**
   - Расхождение с корпусом — по большей части шум (одно чтение омографа, имена): из ~40–100 строк `flag_new.txt` на пару глав реальных ошибок 2–8. Читай каждую строку по контексту, «+» стоит ПЕРЕД ударной гласной (`флот+ы` = флоты́, а не фл+оты).
   - Типовые реальные ошибки: `флот+ы` (верно `фл+оты`), `терп+ит`, `вр+еменная`, `предпринят+а`, `взят+а`, `долож+ите`, `прилож+ите`, `сл+еда`, `тупик+ов`, `м+алого`, `рак+урс(е)`, `геф+есте`, `заряжен+ы`. Предложная форма и родительный у имён цепочка ставит непоследовательно (`Роб+ардс` — `р+обардса`, `Бэрд` — `бэрд+а`): добавляй ВСЕ формы имени, найденные в книге (`grep -a -o "Имя[а-я]*" книга.fb2 | sort | uniq -c`), одним коммитом.
   - Омографы вида существительное/глагол («пропасть», «все/всё равно») закрывай ФРАЗАМИ в файле книги или фразой в общем словаре, а не одиночным словом: общий словарь действует на все книги. Для «все равно» (книга пишет «все» вместо «всё») ключ `все равно` → `вс+ё равн+о`.
   - Фразы, созданные «Анализом омографов», бывают с неверным падежом и ПЕРЕБИВАЮТ словарь: `два станд+артных год+а` (верно `г+ода`), `славного простодушного мал+ого` (перебивало `м+алого`). После добавления слова в словарь ВСЕГДА проверяй его сухим прогоном на предложении из книги; если не сработало — `grep` по корню во всех словарях книги.
   - Имена, ударение которых решает слух (Бэбкок, Одри, Саво, Элис, Робардс, Тобин, Джулиус, Фредерик): не добавляй сам, дай список «под вопросом»; пользователь отвечает формой («Б+эбкок, +Одри, С+аво, +Элис»), тогда добавляй все падежные формы.
   - Причастия на `-ённый` без «ё» в книге (`заряженный` → `заряж+енный`, не `зар+яженный`) цепочка ставит на корень; значение омонима решает смысл (`+отзыв` мнение / `отз+ыв` отзыв посла): второе закрывай фразой в файле книги (`об отзыве с` → `об отз+ыве с`).
   - Падежные омографы вроде «орденов» не чини словарём — оставь Silero/шлюзу.
   - Проверка добавленных слов одним скриптом: `stress_dry_run(текст, book_overrides_path="pepel-pobedy.manual_stress_overrides.json")[0]`, вывод писать в файл (см. п. 5).
   - Запись в JSON словарей с CRLF: читать/писать байтами, определять перевод строки (`"\r\n" if "\r\n" in raw`), дописывать записи перед последней `}`, проверять `json.loads` до записи.

9. **Инструмент для сомнительных мест:** вкладка GUI «Сомнительные места» (см. CLAUDE.md) собирает те же расхождения с корпусом, что `flag_vs_corpus.py`, но с контекстом, клипом из готовой главы и записью решения («только здесь» / «везде»). Для разбора вместе с пользователем предлагай её вместо длинных списков в чате.

## 3. Какие главы переозвучить
`.venv\Scripts\python.exe -I stress-listening-session\affected_chapters.py <ревизия до сессии>` → `affected.txt` в cwd: номера в списке (1-based; Глава N = N+1, это же NNN в имени `NNN_Глава N.wav`) и затронутые ключи. Фразовые ключи входят в отпечаток каждой главы, так что программа сама пересинтезировала бы всю книгу — выборку по `--chapters` делай по этому списку.

## 4. Пересинтез (только по просьбе «переделай»/«запусти книгу»)
1. **Бэкап** выбранных глав в `_archive\before_<тема>_<дата>\` (`cp -p audiobook_output5/NNN_*.wav*`; `_archive` в `.gitignore`; на J: свободно 300+ ГБ, вся книга ≈ 6 ГБ).
2. Сервис: `.venv\Scripts\python.exe fb2_reader.py serve-silero --host 127.0.0.1 --port 5010` (Bash `run_in_background`; запуск через `nohup … &` НЕ срабатывает). Ждать порт: Monitor `until curl -s -m 2 localhost:5010/ >/dev/null; do sleep 3; done` (404 на `/` — нормально).
3. Прогон — команда из `stress-book-run`, плюс `--chapters 3-12,16,…` (номера в списке) и `--stress-engine silero`; в фоне, ждать Monitor-ом по строке `Готово. Файлы сохранены`. 2 главы ≈ 2 мин, 29 глав ≈ 40–60 мин.
4. После: проверить число переписанных `.wav` (`ls -l --time-style=+%F_%H:%M`), `grep -ac "Traceback\|ERROR"` в логе, ОСТАНОВИТЬ свой сервис (`netstat -ano | grep ":5010 .*LISTENING"` → `taskkill //F //PID`; бывает два процесса) — иначе он мешает сервису GUI. Сообщение «failed, exit code 1» у фоновой задачи сервиса после этого — ожидаемо.
5. «Из приложения»: `.venv\Scripts\python.exe fb2_reader.py gui` в фоне; нажать «Озвучить» может только пользователь (автозапуска нет). Настройки уже в `config.json`; перед этим сделать бэкап и остановить свой сервис.
6. Сообщать факты; ударение в аудио подтверждает только слух.

## 5. Коммит
Только по просьбе. `git add` явно нужные файлы (`forced_stress_words.json`, `pepel-pobedy.manual_stress_overrides.json`, `pronunciation_substitutions.json`), сообщение `Stress dictionary: … (found in chNN dry run)` + `Co-Authored-By` из системного напоминания; `git status --short` до и после; push в `master`. Не коммитить `fb2_reader_settings.json`, `dialogue_characters.json`, `audiobook_output*/`, `_archive/`.
