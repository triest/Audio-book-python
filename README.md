fb2_reader.py — озвучивание книг в формате FB2 на русском языке.

Быстрый старт на Windows (ничего вручную ставить не нужно)

Двойной клик по run_gui.bat. При первом запуске он сам:
  * найдёт Python на компьютере (если его нет — подскажет, откуда скачать
    и на что нажать при установке);
  * создаст отдельную папку .venv рядом со скриптами и поставит туда все
    нужные пакеты (numpy, torch, silero и т.п.) — это не трогает ничего
    в остальной системе;
  * дополнительно создаст ОТДЕЛЬНОЕ окружение .venv_cosyvoice (свой Python,
    отдельно от .venv выше) для режима клонирования голоса — это большая,
    в несколько гигабайт, установка (PyTorch с поддержкой CUDA, движки
    F5-TTS и XTTS-v2 — см. раздел "Режим cosyvoice" ниже), может занять
    заметное время на медленном интернете. Если вам не нужно клонирование
    голоса — эта часть просто не мешает, остальные режимы (silero и т.д.)
    от неё не зависят;
  * после этого откроет окно программы.

Повторные запуски run_gui.bat уже ничего не переустанавливают — сразу
открывают программу. Если нужно только поставить/обновить зависимости
без запуска — есть отдельный install.bat.

Если очень хочется единый .exe-файл без Python вообще на компьютере —
есть experimental build_exe.bat (собирает такой .exe через PyInstaller
после того, как install.bat/run_gui.bat хоть раз отработали) — подробности
и оговорки в комментариях внутри самого файла. Для большинства случаев
run_gui.bat удобнее: файл лёгкий, обновляется вместе с остальным кодом, и
не нужно пересобирать после каждого изменения.

Графический интерфейс (запуск вручную, без .bat-файлов):
  python3 fb2_reader.py              # без аргументов — откроется окно
  python3 fb2_reader.py --gui
  python3 fb2_reader_gui.py
  run_gui.bat                        # Windows, можно перетащить .fb2 на файл

Командная строка (как раньше):
  python3 fb2_reader.py book.fb2 --mode silero --speaker xenia
  run_cli.bat book.fb2 --mode silero --speaker xenia   # Windows

Возможности:
  * извлечение текста из .fb2 (и .fb2.zip) по главам;
  * озвучка несколькими способами:
      1) silero      — нейросетевой синтез Silero TTS локально через
                       torch.hub, без отдельного сервера. Живая интонация,
                       естественные паузы на знаках препинания, ударения
                       расставляются автоматически. Модель скачивается один
                       раз (~50-100 МБ), дальше работает офлайн. Требует torch.
      2) silero_rest — синтез через локальный REST-сервис
                       silero_rest_service.py (форк
                       https://github.com/Flokss/Silero-REST-Service).
                       Текст главы автоматически превращается в SSML —
                       добавляются интонационные паузы на запятых, тире и
                       двоеточиях, более длинные паузы между предложениями
                       и абзацами, а вопросительные и восклицательные знаки
                       сохраняются как есть, поэтому Silero озвучивает
                       вопросы и восклицания с соответствующей интонацией.
                       Требует запущенного рядом сервиса (см. раздел ниже)
                       и пакета requests.
      3) cosyvoice   — клонирование голоса по короткому аудио-образцу
                       (F5-TTS-Russian по умолчанию, XTTS-v2 как запасной
                       движок) — озвучивает книгу ВАШИМ выбранным голосом
                       (или любым другим, для которого есть образец), а не
                       готовым набором дикторов. Подробности, установка,
                       ограничения — отдельный большой раздел ниже.
      4) piper       — локальный синтез Piper TTS, работает на CPU (видео-
                       карта не нужна), заметно быстрее cosyvoice/silero на
                       слабом железе, но без клонирования голоса — только
                       готовый набор голосов.
      5) yandex      — облачный Yandex SpeechKit, платный, нужен интернет
                       и API-ключ, подробности в разделе ниже.
      6) qwen_tts    — облачный Qwen3-TTS через Alibaba DashScope, платный,
                       нужен API-ключ (и, для карт из РФ, обходной путь
                       оплаты) — подробности в разделе ниже.
      7) qwen_tts_local — тот же Qwen3-TTS, но считается на вашей
                       ВИДЕОКАРТЕ через отдельно установленный локальный
                       сервер (Pinokio) — бесплатно, без интернета и без
                       карты. Полная пошаговая инструкция по установке — в
                       разделе ниже.
      8) online      — через gTTS (Google Text-to-Speech), нужен интернет
                       на каждый запуск, голос неплохой, но менее выразительный.
      9) offline     — через pyttsx3 и системный TTS (espeak и т.п.), самое
                       низкое качество, зато совсем без интернета и без torch.

Установка зависимостей:
  # для локального режима silero (лучшее качество голоса):
  pip install silero torch torchaudio omegaconf numpy

  # для режима silero_rest (клиент + сам сервис):
  pip install requests numpy fastapi uvicorn torch ruaccent num2words

  # для остальных режимов:
  pip install gTTS pyttsx3 lxml pydub

Если команда "pip" не находится напрямую, используйте "python3 -m pip ..."
вместо "pip ...".

Проигрывание готовых файлов (кнопка "Прослушать выбранную главу" и опция
"Проигрывать после озвучки") теперь не требует pygame — используются
средства, которые уже есть в системе: winsound для .wav на Windows
(входит в Python "из коробки") или открытие файла проигрывателем по
умолчанию (os.startfile / afplay / xdg-open). pygame ставить не нужно —
и хорошо, потому что на новых версиях Python (например 3.14) у pygame
может не быть готового wheel под Windows, и попытка "pip install pygame"
пробует собрать его из исходников, для чего нужен компилятор Visual
Studio — без него установка падает с ошибкой вида
"No module named 'distutils.msvccompiler'". Если вы уже сталкивались с
этой ошибкой — просто не устанавливайте pygame, программа прекрасно
обойдётся без него.

Для offline-режима (pyttsx3) на Linux дополнительно нужен espeak-ng:
  sudo apt install espeak-ng

Режим silero_rest: как запустить

В графическом интерфейсе отдельная консоль не нужна: если в блоке
настроек включена галочка «Запускать сервис Silero REST автоматически
(без консоли)» (включена по умолчанию) и REST URL указывает на localhost
— при старте озвучки в режиме silero_rest программа сама, в фоне,
запускает silero_rest_service.py и ждёт, пока он не станет отвечать
(при первом запуске это может занять несколько минут — скачивается
модель). Ход запуска видно в «Журнале» окна строками вида
«[сервис Silero REST] …». Если запустить не удалось — там же будет
понятная причина. Сервис, запущенный так, при закрытии окна программа
предложит остановить вместе с ним (можно оставить работать и дальше,
тогда следующий запуск подключится к уже готовому сервису мгновенно).

Ручной запуск (нужен для командной строки без GUI, или если галочку
автозапуска выключили) — 2 окна терминала:

Окно 1 — сервис (держать открытым всё время озвучки, не закрывать,
не нажимать Ctrl+C):

  cd audiobook
  python3 silero_rest_service.py

Дождитесь в выводе:

  Downloading Silero TTS model...          # только при первом запуске, ~50-100 МБ
  TTS Model loaded successfully
  RUAccent model loaded successfully
  INFO:     Uvicorn running on http://0.0.0.0:5010

Пока этих строк нет — сервис ещё не готов принимать запросы. Если сервис
остановится или не был запущен, fb2_reader.py в режиме silero_rest начнёт
падать с ошибкой:
  "Подключение не установлено, т.к. конечный компьютер отверг запрос на
   подключение" (WinError 10061)
— это значит, что порт 5010 никто не слушает: проверьте, что окно с
сервисом открыто и в нём видна строка "Uvicorn running on ...".

Окно 2 — сама озвучка (запускать только после того, как сервис поднялся):

  python3 fb2_reader.py book.fb2 --mode silero_rest --rest-url http://localhost:5010 --speaker xenia --outdir audiobook

Флаги для настройки интонационных пауз в режиме silero_rest:
  --sentence-break-ms   (по умолчанию 320) — пауза между предложениями
  --paragraph-break-ms  (по умолчанию 550) — пауза между абзацами
  --comma-break-ms      (по умолчанию 180) — пауза на запятых/тире/двоеточиях

Примеры запуска:
  # Графический интерфейс (выбор книги, голоса, режима)
  python3 fb2_reader.py --gui
  # или двойной клик по run_gui.bat (Windows)

  # Лучшее качество без сервиса: нейросетевой голос Silero локально
  python3 fb2_reader.py book.fb2 --mode silero --speaker xenia --outdir audiobook

  # То же самое, но сразу слушать по мере озвучки
  python3 fb2_reader.py book.fb2 --mode silero --play

  # Через локальный Silero-REST-Service с интонационными паузами (SSML);
  # сервис должен быть уже запущен в отдельном окне (см. выше)
  python3 fb2_reader.py book.fb2 --mode silero_rest --rest-url http://localhost:5010 --speaker xenia --outdir audiobook

  # Озвучить книгу через gTTS и сразу проигрывать
  python3 fb2_reader.py book.fb2 --mode online --play

  # Офлайн pyttsx3-режим, начиная с 3-й главы
  python3 fb2_reader.py book.fb2 --mode offline --start 3

  # Просто посмотреть список глав, ничего не озвучивая
  python3 fb2_reader.py book.fb2 --list

Доступные модели Silero (--model):
  v5_5_ru — последняя (ударения, омографы, вопросы), по умолчанию
  v5_4_ru, v5_ru, v4_ru (устаревшая, голос random)

Голоса (--speaker): aidar (муж.), baya (жен.),
kseniya (жен.), xenia (жен.), eugene (муж.), random (только v4_ru).

Пример с последней моделью:
  python3 fb2_reader.py book.fb2 --mode silero --model v5_5_ru --speaker xenia

silero_rest_service.py — локальный REST-сервис (FastAPI)

Форк https://github.com/Flokss/Silero-REST-Service, дополненный поддержкой
SSML для интонационных пауз.

Эндпоинты:
  GET /getwav?text_to_speech=<текст>&speaker=xenia&sample_rate=24000
      — как в оригинальном сервисе: обычный текст без пауз/SSML.

  GET /getssmlwav?text_to_speech=<текст или SSML>&speaker=xenia&sample_rate=48000&raw_ssml=false
      — с интонационными паузами. Если raw_ssml=false (по умолчанию),
      text_to_speech передаётся как обычный текст, и сервис сам оборачивает
      его в SSML (<speak><p><s>...</s></p></speak>) с паузами на знаках
      препинания и границах предложений/абзацев. Если raw_ssml=true —
      text_to_speech должен быть уже готовым SSML-документом (именно так
      его посылает fb2_reader.py в режиме --mode silero_rest).
      Дополнительные параметры: sentence_break_ms, paragraph_break_ms,
      comma_break_ms — длительности пауз в миллисекундах.

При первом запуске сервис скачивает модель Silero (silero_model_v5_5_ru.pt,
~50-100 МБ) и модель RUAccent для расстановки ударений — это разовая
операция, дальше сервис стартует быстро и работает офлайн.

Улучшения интонации и графический интерфейс (обновление август 2026)

  * Локальный режим silero (без отдельного сервиса) теперь тоже расставляет
    интонационные паузы по знакам препинания — раньше паузы по пунктуации
    были только в режиме silero_rest. Текст главы делится на короткие
    куски по запятым/тире/двоеточиям, границам предложений и абзацев, и
    между ними вставляется пауза соответствующей длины (короткая на
    запятой, побольше между предложениями, самая длинная между абзацами).
  * Настройки пауз (запятые/предложения/абзацы), ударений (автоматическая
    расстановка и буква "ё") и усиления интонации вопросов/восклицаний
    теперь вынесены в графический интерфейс — не нужно запускать из
    командной строки, чтобы их поменять. Блок «Интонация и паузы» в
    правой колонке окна.
  * В локальном режиме silero пропуски фрагментов из-за ошибок синтеза
    стали значительно реже и заметнее: при сбое фрагмент сначала
    пробуется ещё раз, затем делится пополам и озвучивается по частям, и
    только если совсем ничего не помогло — на его место вставляется
    короткая тишина с явным сообщением в журнале (вместо того чтобы
    молча пропускать текст).
  * Кнопка «Обновления…» рядом с выбором модели в интерфейсе проверяет на
    GitHub (репозиторий silero-models), не вышла ли более новая версия
    русской модели Silero, и сообщает об этом в журнале — ничего не
    скачивает автоматически, но подсказывает, что добавить в
    silero_config.py. То же самое из командной строки: --check-model-updates.
  * В список моделей добавлены промежуточные версии v5.1–v5.3 (между
    v5.0 и текущей последней v5.5), которых раньше не было в выборе.

Улучшения интонации (более раннее обновление)

  * Модель Silero v5_5_ru — последняя на август 2026: ударения, омографы,
    вопросительная интонация. Выбирается через --model v5_5_ru (по умолчанию)
    или в GUI в поле «Модель». Загрузка: pip install silero, иначе torch.hub.
  * Модель Silero обновлена с v4_ru на v5_5_ru — она официально умеет сама
    расставлять ударения, разрешать омографы (за́мок/замо́к) и строить
    вопросительную интонацию без дополнительной разметки. Голоса и API те
    же (aidar, baya, kseniya, xenia, eugene), это прямая замена. Файл
    модели называется по-другому (silero_model_v5_5_ru.pt), чтобы не
    подхватить случайно старый закэшированный v4 — при первом запуске
    после обновления модель скачается заново.
  * Вопросительные и восклицательные предложения в режиме silero_rest
    дополнительно оборачиваются в SSML-тег <prosody pitch="high"[ rate=
    "fast"]> — усиливает интонацию поверх того, что модель и так делает по
    самому знаку "?"/"!" (особенно заметно на репликах в кавычках).
    Отключается флагом --no-emphasis.
  * Сервис теперь всегда расставляет ударения (RUAccent) в текстовых
    узлах SSML — раньше это делалось только для обычного текста
    (/getwav и /getssmlwav?raw_ssml=false), а SSML, присланный клиентом
    (fb2_reader.py в режиме silero_rest), уходил на синтез без ударений.
  * Исправлена опечатка в параметрах RUAccent: 'turbo' не существует как
    значение omograph_model_size в актуальных версиях библиотеки —
    заменено на 'turbo3.1' (актуальные варианты: tiny, tiny2, tiny2.1,
    turbo2, turbo3, turbo3.1, big_poetry), даёт заметно лучшее качество
    расстановки ударений.

Режим yandex — Yandex SpeechKit (облачный, платный)

Это ещё один способ озвучки, добавленный по запросу — облачный синтез
речи от Яндекса. В отличие от Silero он не бесплатный и не локальный:
нужен интернет на каждую главу, аккаунт в Yandex Cloud и API-ключ, а
после пробного периода — оплата по количеству символов. Даёт неплохие
голоса с интонациями (некоторые поддерживают эмоции good/neutral/evil),
но для большинства сценариев в этом проекте локальный Silero остаётся
основным вариантом — он бесплатный, работает офлайн и теперь тоже
умеет паузы по пунктуации.

Подробная пошаговая инструкция, откуда брать ключ (включая более новый
и короткий путь через AI Studio) — в отдельном файле
ОТКУДА_ВЗЯТЬ_КЛЮЧ_ЯНДЕКС.md рядом с этим README. Коротко:

  1. Зайдите на https://aistudio.yandex.ru под своим Яндекс-аккаунтом
     (или создайте его). Обычно нужно привязать платёжный аккаунт и
     активировать пробный период — без этого сервисы, включая
     SpeechKit, не включатся, даже если сначала ничего не потратится.
  2. Откройте свой каталог -> раздел "Доступ" (Access) — адрес вида
     https://aistudio.yandex.ru/platform/folders/<folder id>/access —
     и создайте там сервисный аккаунт с ролью ai.speechkit-tts.user
     (доступ к синтезу речи), если его ещё нет.
  3. Выпустите для этого аккаунта API-ключ. Ключ показывается только
     один раз в момент создания — сразу скопируйте его.
  4. Этот ключ вставьте в поле «API-ключ» в программе (или передайте
     через --yandex-api-key / переменную окружения YANDEX_API_KEY).

(Есть и альтернативный путь через классическую консоль Yandex Cloud —
IAM -> Сервисные аккаунты — он тоже работает и подробно описан в
ОТКУДА_ВЗЯТЬ_КЛЮЧ_ЯНДЕКС.md, на случай если у вас показывается другой
интерфейс.)

Folder ID для этого способа (ключ сервисного аккаунта) передавать НЕ
обязательно — SpeechKit сам знает, в каком каталоге создан аккаунт,
выпустивший ключ. Поле «Folder ID» в программе можно оставить пустым.
Указывать Folder ID нужно только при другом, менее удобном способе
авторизации (IAM-токен пользовательского аккаунта) — этот скрипт его не
использует, поле оставлено на случай, если он вам зачем-то понадобится.

В графическом интерфейсе оба поля и выбор голоса — в блоке
«Yandex SpeechKit (режим yandex)» справа. Из командной строки:

  python3 fb2_reader.py book.fb2 --mode yandex \
      --yandex-api-key <ключ> --yandex-folder-id <id> \
      --yandex-voice alena --outdir audiobook

Доступные голоса (--yandex-voice): alena, filipp, ermil, jane, madirus,
omazh, zahar, lera — список актуальных голосов SpeechKit периодически
пополняется, точный и самый свежий список смотрите в консоли Yandex
Cloud или документации SpeechKit (https://yandex.cloud/ru/docs/speechkit/tts/voices).
Для ermil и jane можно дополнительно задать --yandex-emotion
(good/neutral/evil).

Официальная документация REST API синтеза:
https://yandex.cloud/ru/docs/speechkit/tts/request

Режим qwen_tts / qwen_tts_local — Qwen3-TTS (облачный и локальный)

Ещё один способ озвучки — Qwen3-TTS от Alibaba. Есть ДВА варианта, у них
разные плюсы и минусы, но общий движок:

  * qwen_tts       — облачный, через сервис Alibaba DashScope. Платный
                      (после пробных бесплатных лимитов), нужен интернет
                      на каждый запрос и API-ключ. Плюс: не нужна своя
                      видеокарта. Минус: карты, выпущенные в РФ, сервис
                      DashScope на этапе регистрации аккаунта не принимает
                      (см. ниже).
  * qwen_tts_local — тот же движок Qwen3-TTS, но считается локально на
                      ВАШЕЙ видеокарте через отдельно установленный
                      Gradio-сервер (проще всего — через оболочку
                      Pinokio). Полностью бесплатно, без интернета и без
                      банковской карты, но требует один раз вручную
                      поставить Pinokio + модель (несколько ГБ) и
                      современную видеокарту с CUDA.

Голоса у облачного и локального вариантов РАЗНЫЕ (это разные наборы,
не пересекаются) — программа сама показывает нужный список в
зависимости от выбранного режима.

### Облачный режим (qwen_tts)

Подробная инструкция, где взять API-ключ (включая то, что старая консоль
dashscope.console.aliyun.com выключена и переехала на Bailian/Model
Studio) — в отдельном файле ОТКУДА_ВЗЯТЬ_КЛЮЧ_QWEN.md рядом с этим
README. Коротко:

  1. Зайдите на https://modelstudio.console.aliyun.com (международная,
     англоязычная консоль) и создайте аккаунт Alibaba Cloud.
  2. На этапе привязки платёжного способа имейте в виду: карты,
     выпущенные российскими банками, Alibaba Cloud на данный момент не
     принимает (блокировка на уровне BIN карты, а не конкретно
     санкционная — так у многих). Рабочие обходные пути — виртуальная
     карта зарубежного банка/сервиса (Wise и подобные, если доступны) или
     сторонний сервис-посредник для оплаты китайских/международных
     сервисов. Если возиться с этим не хочется — используйте локальный
     режим qwen_tts_local ниже, для него карта не нужна вообще.
  3. Создайте API-ключ на странице
     https://modelstudio.console.aliyun.com/?tab=playground#/api-key
     и вставьте его в программе, в блоке «Qwen3-TTS», в поле «API-ключ»
     (или передайте через --qwen-api-key / переменную окружения
     DASHSCOPE_API_KEY).

  python3 fb2_reader.py book.fb2 --mode qwen_tts \
      --qwen-api-key <ключ> --qwen-voice Cherry --outdir audiobook

Голоса облачного варианта (--qwen-voice): Cherry, Serena, Ethan, Vivian,
Ryan.

Примечание: облачная интеграция написана по документации DashScope, но
не проверялась вживую на реальном оплаченном аккаунте (см. обходной путь
выше) — если что-то не заработает с первого раза, пришлите мне текст
ошибки.

### Локальный режим (qwen_tts_local) — без интернета и без карты

Работает на вашей видеокарте через отдельно установленный локальный
Gradio-сервер. Программа сама запускает и останавливает этот сервер по
мере необходимости (см. ниже) — вручную нужно только один раз поставить
саму программу-оболочку Pinokio и модель внутри неё.

Шаг 1. Установите Pinokio:

  1. Скачайте установщик с https://pinokio.co (или прямая ссылка
     https://get.pinokio.co) — там же выберите Windows.
  2. Запустите скачанный установщик, пройдите обычную установку (Next /
     Install), дождитесь запуска Pinokio.

Шаг 2. Установите Qwen3-TTS внутри Pinokio:

  1. В Pinokio откройте раздел с каталогом приложений (значок "магазина"
     / Discover) и найдите там карточку "Qwen3-TTS" (сборка от
     SUP3RMASSIVE, репозиторий
     https://github.com/SUP3RMASSIVE/Qwen3-TTS-Pinokio). Если не находится
     поиском — можно добавить по прямой ссылке на репозиторий через
     "Download from URL"/аналогичную кнопку в интерфейсе Pinokio.
  2. Нажмите Install / Download и дождитесь окончания установки — Pinokio
     сам поставит нужное окружение Python и скачает модель Qwen3-TTS
     (несколько ГБ, требует свободного места на диске и времени на
     скачивание).
  3. После установки на карточке приложения откройте её и нажмите Run —
     Pinokio запустит сервер, откроется вкладка с интерфейсом.

Шаг 3. Включите автозапуск сервера (чтобы не приходилось нажимать Run
каждый раз вручную):

  1. На карточке приложения Qwen3-TTS откройте настройки автозапуска
     (обычно шестерёнка / кнопка "Autolaunch" на самой карточке).
  2. Выберите скрипт запуска "Terminal — start.json" (именно тот, что
     запускает сервер, а не установку/обновление).
  3. Включите переключатель "Start with Pinokio" — тогда сервер будет
     сам подниматься при каждом запуске самого Pinokio.
  4. Если хотите совсем без ручных действий при перезагрузке компьютера —
     добавьте ярлык Pinokio в автозагрузку Windows (Win+R -> shell:startup
     -> поместить туда ярлык программы Pinokio).

Шаг 4. Узнайте адрес сервера:

  1. Откройте вкладку "Terminal" на карточке приложения Qwen3-TTS в
     Pinokio (там видно живой лог запуска).
  2. Найдите строку вида "Running on local URL: http://127.0.0.1:7860" —
     это и есть адрес локального сервера. Обычно порт 7860 (стандартный
     для Gradio) и не меняется между запусками, но проверяйте по логу,
     если сомневаетесь.

Шаг 5. Настройте программу:

В графическом интерфейсе, в блоке «Qwen3-TTS» справа (может понадобиться
прокрутить панель настроек вниз — блок с выбором голоса Qwen3-TTS
находится ниже остальных полей) — раздел «Локальный режим»:

  * «Адрес сервера» — вставьте адрес из шага 4 (по умолчанию уже
    подставлен http://127.0.0.1:7860 — обычно менять не нужно).
  * «Команда автозапуска сервера» — необязательное поле. Если сервер уже
    настроен на автозапуск вместе с Pinokio (шаг 3), можно оставить
    пустым — программа просто проверит, что сервер отвечает, и будет
    использовать его. Заполняйте, только если хотите, чтобы САМА
    программа fb2_reader запускала сервер по требованию (например,
    команда, которая открывает Pinokio, если он не запущен).
  * «Останавливать сервер автоматически после озвучки» — если включено
    (по умолчанию так) и сервер запустила именно эта программа (не вы
    вручную и не через автозапуск Pinokio), она же его и остановит после
    завершения озвучки. Сервер, который уже был запущен независимо от
    программы (вручную или через Pinokio), она не трогает и не
    останавливает.
  * Голос выбирается там же, в выпадающем списке (список голосов у
    локального режима свой, отдельный от облачного — см. ниже).

Из командной строки:

  python3 fb2_reader.py book.fb2 --mode qwen_tts_local \
      --qwen-local-url http://127.0.0.1:7860 \
      --qwen-local-voice Serena --outdir audiobook

Голоса локального варианта (--qwen-local-voice): Aiden, Dylan, Eric,
Ono_anna, Ryan, Serena, Sohee, Uncle_fu, Vivian.

Если у вас другая версия/сборка Gradio-демо Qwen3-TTS в Pinokio — набор
функций и параметров может отличаться от того, что зашито в программе.
Актуальную схему конкретно вашего сервера всегда можно посмотреть по
адресу <адрес сервера>/?view=api (или по ссылке "Use via API" внизу
страницы интерфейса) — если что-то не совпадает и синтез не запускается,
пришлите мне содержимое этой страницы, поправлю вызов под вашу версию.

Настройки качества (заданы в коде, можно поменять при желании — константы
в начале fb2_reader.py):

  * QWEN_TTS_LOCAL_MAX_CHARS = 500 — размер куска текста на один запрос к
    модели. Больше — меньше "швов" между кусками, но модель может не
    успеть договорить длинный кусок за один вызов и он обрежется
    (проверено на практике: 1800 символов уже давало недоозвученные
    главы). 500 — безопасный компромисс.
  * QWEN_TTS_LOCAL_SEED = 42 — фиксированный сид генерации. Без него
    (случайный сид на каждый кусок) интонация и тембр заметно "скачут"
    между соседними кусками одной главы.
  * QWEN_TTS_LOCAL_INSTRUCT — текстовая инструкция об интонации,
    отправляемая модели (по умолчанию — нейтральное спокойное
    повествование). Пустая инструкция отдаёт выбор интонации на откуп
    модели, из-за чего озвучка может звучать излишне театрально/
    эмоционально — при желании отредактируйте текст инструкции под свой
    вкус.

Частые проблемы этого режима:

  * "Cannot find a function with api_name: ..." — сигнатура API у вашей
    сборки сервера отличается от той, что зашита в программе. Откройте
    <адрес сервера>/?view=api и пришлите мне содержимое страницы.
  * Сервер не отвечает / таймаут — проверьте, что Pinokio запущен и
    карточка Qwen3-TTS либо уже в состоянии Running, либо у неё включён
    автозапуск (шаг 3 выше); либо укажите команду автозапуска в
    настройках программы.
  * Озвучена не вся глава / обрывается на середине куска — уменьшите
    QWEN_TTS_LOCAL_MAX_CHARS в коде (см. выше).
  * Слишком эмоциональная/театральная озвучка — отредактируйте
    QWEN_TTS_LOCAL_INSTRUCT в коде, сделав инструкцию более сдержанной.

Режим cosyvoice — клонирование голоса (F5-TTS-Russian / XTTS-v2)

В отличие от всех остальных режимов, где голос выбирается из готового
списка дикторов, здесь голос озвучки клонируется по короткому аудио-
образцу — можно озвучить книгу практически любым голосом, для которого
есть чистая запись в несколько секунд (свой собственный, актёра
озвучивания из другой книги и т.п.).

Работает через отдельный HTTP-сервис (cosyvoice_rest_service.py),
запущенный в своём окружении .venv_cosyvoice (см. install.bat выше) —
программа запускает и останавливает его сама в фоне, без отдельного окна
консоли; ход запуска виден в «Журнале» строками вида
«[сервис CosyVoice] …». Название режима/файлов осталось "cosyvoice" по
историческим причинам (изначально использовалась модель CosyVoice2), но
сама она больше не используется — от неё отказались, потому что она не
обучена на русском языке и на русском тексте выдавала невнятную "кашу".

Два движка синтеза, переключаются на вкладке «Голоса CosyVoice» выпадающим
списком «Движок синтеза» (при смене сервис сам перезапускается, голоса
переклонировать не нужно — они общие для обоих движков):

  * F5-TTS-Russian (по умолчанию, рекомендуется) — чекпоинт
    hotstone228/F5-TTS-Russian на HuggingFace, дообученный именно на
    русской речи (Common Voice, SOVA RUDevices, SberDevices Golos).
    Ударения и произношение заметно естественнее, чем у общей
    мультиязычной модели, потому что модель реально училась на русском.
    Лицензия чекпоинта — CC-BY-NC-SA (некоммерческое использование).
    Для качественного клонирования нужен текст того, что сказано в
    образце — если не указать вручную, сервис сам распознаёт его через
    Whisper при первом использовании голоса и запоминает результат.
  * XTTS-v2 (запасной) — Coqui TTS, официально мультиязычная (17 языков,
    включая русский), но без специализации под русский — ударения на
    русском тексте иногда невпопад (частично компенсируется автоматической
    расстановкой ударений через RUAccent). Текст образца ей не обязателен.
    Сервис использует её автоматически, если F5-TTS-Russian не смогла
    загрузиться (например, из-за проблем с установкой её зависимостей).

Добавление и управление голосами — вкладка «Голоса CosyVoice» вверху окна:
  * «Добавить голос»: выберите аудиофайл-образец (WAV/MP3/FLAC/OGG/M4A,
    в идеале 6-15 секунд чистой речи ОДНОГО голоса, без музыки и шума —
    более длинные образцы автоматически обрезаются), впишите имя и,
    по желанию, точный текст того, что сказано в образце. Кнопка
    «Распознать текст (по аудио)» сама расшифровывает образец через
    Whisper — печатать вручную не обязательно.
  * Добавленные голоса сохраняются постоянно (в CosyVoice/
    cosyvoice_voices.json и CosyVoice/voices/) и остаются доступны после
    перезапуска программы и компьютера — добавлять заново не нужно.
  * «Удалить выбранный голос» в этой же вкладке — убирает голос из списка
    и удаляет его аудиофайл.
  * Каждый диалог выбора файла (книга, папка вывода, образец голоса)
    запоминает свою последнюю открытую папку отдельно от остальных — не
    нужно каждый раз заново переходить в нужное место.

Требования и производительность:
  * Заметно быстрее работает на видеокарте NVIDIA (CUDA) — на CPU одна
    фраза может занимать десятки секунд. install.bat пытается поставить
    CUDA-версию PyTorch автоматически (индекс cu124, при неудаче — cu121,
    и только при неудаче обоих — обычную CPU-сборку). Проверить, какая
    версия реально стоит и видит ли она видеокарту:
      .venv_cosyvoice\Scripts\python.exe -c "import torch; print(torch.__version__, torch.cuda.is_available())"
    Должно быть что-то вида "2.5.1+cu124 True". Если False — переустановите
    вручную (индекс можно заменить на cu121, если cu124 не подходит под
    вашу видеокарту/драйвер):
      .venv_cosyvoice\Scripts\pip.exe uninstall torch torchaudio -y
      .venv_cosyvoice\Scripts\pip.exe install torch torchaudio --index-url https://download.pytorch.org/whl/cu124
  * При первом использовании каждый из движков скачивает свои веса
    (F5-TTS-Russian — ~1.3 ГБ, XTTS-v2 — ~2 ГБ) — разово, дальше берутся
    из локального кэша (CosyVoice/pretrained_models/ и системный кэш
    HuggingFace/TTS). install.bat пытается скачать их заранее при
    установке, чтобы это не откладывалось на первый реальный синтез.
  * Собранный ffmpeg на компьютере не нужен — вся работа с аудио идёт
    через soundfile/torchaudio без внешних зависимостей.

Из командной строки режим называется так же, как раньше:
  python3 fb2_reader.py book.fb2 --mode cosyvoice --cosyvoice-voice <имя_голоса> --outdir audiobook

Лог самого сервиса синтеза — отдельный файл
CosyVoice/cosyvoice_rest_service.log (с ротацией, не растёт бесконечно) —
пригодится, если что-то не заводится, а в окне программы видно не всё.

Частые проблемы

"Подключение не установлено, т.к. конечный компьютер отверг запрос на
подключение" / WinError 10061
  Сервис silero_rest_service.py не запущен или упал. Откройте отдельное
  окно, запустите его командой из раздела "Окно 1" выше и дождитесь строки
  "Uvicorn running on http://0.0.0.0:5010", прежде чем запускать озвучку.

'"pip" не является внутренней или внешней командой...'
  Используйте "python3 -m pip install ..." вместо "pip install ...".

Ссылки Silero (проект, чьи модели тут используются) — где смотреть новости
и обновления моделей

  Модели TTS/ударений, которые использует этот скрипт, делает команда
  Silero. Здесь используется репозиторий silero-models — но у самого
  проекта Silero есть более широкая линейка (детекция голоса, STT и
  т.п.), и обновления удобнее всего отслеживать по этим источникам:

  * GitHub, репозиторий с моделями — ЭТОТ РЕПОЗИТОРИЙ УЖЕ ИСПОЛЬЗУЕТСЯ
    программой напрямую в двух местах: torch.hub.load(repo_or_dir=
    "snakers4/silero-models", ...) в silero_config.py (загрузка модели,
    если пакет silero не установлен) и MODELS_YML_URL — тот самый
    models.yml, из которого кнопка «Обновления…» узнаёт о новых
    версиях и берёт прямые ссылки на модели. Ничего дополнительно
    подключать не нужно — альтернатив с более новыми моделями или
    лучшим качеством на данный момент нет, репозиторий активно
    поддерживается, а pip install silero и torch.hub — по данным самого
    проекта, один и тот же код:
    https://github.com/snakers4/silero-models

  * Официальный сайт Silero:
    https://silero.ai

  * Официальный Telegram-канал с новостями о релизах моделей:
    https://t.me/s/silero_news

  * Хабр — все статьи с тегом [silero] (релизы, разборы, бенчмарки):
    https://habr.com/ru/search/?q=%5Bsilero%5D&target_type=posts

  * Хабр — блог автора и одного из основателей проекта (snakers4),
    там тоже часто первыми появляются анонсы:
    https://habr.com/ru/users/snakers4/comments/

  * PyTorch Hub — официальная страница модели (та же, что используется
    в этом скрипте через torch.hub.load, если пакет silero не установлен):
    https://pytorch.org/hub/snakers4_silero-models_tts/

  * PyPI — пакет silero (pip install silero), тоже видно версии релизов:
    https://pypi.org/project/silero-tts/

  Что где смотреть:

    (models.yml) и Telegram-канал; это же можно проверить кнопкой
