# Образец книги: ударения + интонации (smart-emotion, встроенная LLM)

Дополняет `stress-book-run` (инкрементальный прогон в `audiobook_output5`) и `stress-listening-session` (цикл «послушал → поправь»).

## Что умеет встроенная LLM (замерено)
- Сервис `llm_rest_service.py` (порт 5013, `.venv_llm`, Qwen2.5-7B-Instruct Q4_K_M, llama-cpp-python cu124), грузится лениво, выгружается через 120 с простоя; ставит `install.bat`.
- **Эмоции абзацев — годится:** 69 абзацев за ~16 с, метки neutral/joy/sadness/fear/anger/calm; на полной книге 50/50 глав размечены без сбоев.
- **Ударения — НЕ годится:** gold 38%, словарные кейсы 63%, CAPS/few-shot-промпт лучше не стал. Источник ударений — словари + silero-stress + шлюз. Кнопка «Спросить LLM» — только подсказка (`tools/llm_stress_benchmark.py` — повторный замер).
- LLM-функции глобально выключены (`AUDIOBOOK_LLM_FEATURES=0`), провайдер `builtin` исключён из запрета (`_llm_provider_allowed`); атрибуция говорящих остаётся выключенной.

## Подготовка машины
1. Нужны ~8 ГБ свободной VRAM под LLM + Silero. ComfyUI (`N:\Comfy-Desktop`, порт 8199) занимает ~15 ГБ VRAM/16 ГБ RAM — **не убивать самому**, попросить пользователя закрыть; фоновые задачи при нехватке памяти убиваются системой.
2. Silero REST должен слушать :5010 (`netstat -ano | findstr :5010`), у сервиса нет SERVICE_VERSION — перезапуск = `taskkill /PID` по netstat.
3. Модель LLM: `llm_models\*.gguf` (если нет — `.venv_llm\Scripts\python.exe llm_rest_service.py --download`).

## Запуск
Из корня, в фоне, лог в scratchpad; параметры голоса — как у основной книги (`stress-book-run`), но `--outdir sample_book` и:
```
--smart-emotion --attribution-provider builtin
```
(`--attribution-model` не нужен.) Сервис LLM поднимается сам (`stress_llm.ensure_builtin_service`). Лог эмоций ищи в консоли; ошибки синтеза — `sample_book\silero_rest_client.log`. Образец: 50 файлов, ~6,1 ГБ, ~18,9 ч, ~сутки-полдня на RTX 4060 Ti.
После прогона остановить свои сервисы Silero (:5010) и LLM (:5013) — не трогая чужие процессы.

## Честные границы
- Идеальные ударения/интонации **не гарантируются**; верность проверяет только слух. ASR проверяет лишь, что текст произнесён.
- Открытые сомнения (решает слух): Барнетт, Фаррагут, Парнелл, Аид, Лестер, Хавьер, Элен, Дюпре, Хассан, «изо всех сил», «сектор+ах/ов», «кр+яжей», «ч+ужды», «тих+онько», «лид+аров», «кое-что» (односложное, снимает `strip_monosyllable_stress`), «четырёхугольником».
- Ударения имён решает пользователь на слух, не ассистент.
- После жалоб: правка в `forced_stress_words.json` / файле книги → пересинтез ТОЛЬКО затронутых глав (`--chapters`, бэкап в `_archive\`). `sample_book/`, `.venv_llm/`, `llm_models/` — в `.gitignore`, не коммитить.
