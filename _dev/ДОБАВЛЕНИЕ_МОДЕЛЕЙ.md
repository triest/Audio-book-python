# Как добавить новую модель Silero

## Способ 1 (проще): кнопка «Обновления…» в программе

Теперь это делается автоматически, руками ничего редактировать не нужно.

1. Откройте программу, нажмите кнопку **«Обновления…»** рядом с полем
   «Модель».
2. Она сверяется с GitHub (реестром моделей Silero) и, если находит
   версию новее той, что уже есть в списке — покажет всплывающее окно
   с вопросом «Добавить их автоматически?».
3. Нажмите **«Да»**. Программа сама скачает не саму модель (только
   ссылку на неё), допишет новую запись в `silero_config.py` и сразу
   добавит модель в выпадающий список «Модель» — перезапускать программу
   не нужно.
4. Голоса для новой модели программа берёт по умолчанию такие же, как у
   текущей последней модели (`v5_5_ru`: aidar, baya, kseniya, xenia,
   eugene) — это предположение, а не гарантия. Если у новой модели голоса
   на самом деле другие, лишний голос просто не сработает при озвучке
   (ошибка будет понятной, ничего не сломается) — тогда список голосов
   для этой модели можно поправить вручную (см. способ 2 ниже, шаг про
   `speakers`).
5. Сама модель (файл `.pt`, обычно 50–100 МБ) скачается один раз при
   первой попытке ей что-то озвучить — так же, как для всех остальных
   моделей.

Если способ 1 почему-то не подходит (например, нет доступа к
GitHub с этого компьютера, но ссылку на модель вы знаете из другого
источника) — ниже описан способ добавить модель руками.

## Способ 2 (руками): править silero_config.py

Модели живут в одном месте — словаре `SILERO_MODELS` в файле `silero_config.py`.
Чтобы добавить новую модель, нужно дописать в этот словарь ещё одну запись
и (при желании) сделать её моделью по умолчанию. Больше нигде ничего менять
не нужно — GUI и командная строка берут список моделей прямо из этого
словаря.

### 1. Откуда брать модели

Официальный источник — реестр моделей проекта Silero на GitHub:

  https://raw.githubusercontent.com/snakers4/silero-models/master/models.yml

Это обычный текстовый файл (YAML), в нём есть раздел `tts_models: -> ru:`,
где перечислены все версии русской модели с прямыми ссылками на файлы
`.pt`. Открыть его можно в браузере или посмотреть только нужный кусок
командой (если есть доступ в интернет и curl):

```
curl -s https://raw.githubusercontent.com/snakers4/silero-models/master/models.yml | grep -A 4 "v5_5_ru:"
```

Кнопка **«Обновления…»** рядом с выбором модели в GUI (и флаг
`--check-model-updates` в командной строке) как раз сверяется с этим
файлом и говорит, есть ли модели новее тех, что уже в программе — но
сама она их не добавляет, только подсказывает id.

Нас интересуют записи вида `vN_ru`, `vN_M_ru` (например `v5_5_ru`,
`v6_ru`, если такая появится) — это основные многоголосые русские модели.
Остальные записи в том же разделе (`v5_turkic`, `aidar_8khz`,
`ru_v3` и т.п.) — это либо модели для других языков СНГ, либо старые
однослойные форматы, они этому скрипту не подходят.

### 2. Что скопировать из models.yml

Для найденной модели, например:

```yaml
    v5_6_ru:
      latest:
        example: 'Меня зовут Лева Королев...'
        package: 'https://models.silero.ai/models/tts/ru/v5_6_ru.pt'
        sample_rate: [8000, 24000, 48000]
```

нужны две вещи:
* **id** модели — `v5_6_ru` (ключ в YAML);
* **package** — прямая ссылка на файл `.pt`.

### 3. Как вписать в silero_config.py

Открой `silero_config.py`, найди словарь `SILERO_MODELS` — это список
блоков вида:

```python
"v5_5_ru": {
    "title": "Silero v5.5 — последняя (ударения, омографы, вопросы)",
    "package_url": "https://models.silero.ai/models/tts/ru/v5_5_ru.pt",
    "local_file": "silero_model_v5_5_ru.pt",
    "speakers": ("aidar", "baya", "kseniya", "xenia", "eugene"),
},
```

Скопируй такой блок, замени в копии:
* ключ (`"v5_5_ru"` → `"v5_6_ru"`);
* `title` — любое понятное описание, оно и покажется в выпадающем списке
  GUI;
* `package_url` — ссылка из `package` в models.yml;
* `local_file` — имя, под которым модель сохранится на диск при первом
  скачивании (обычно просто `silero_model_<id>.pt`, чтобы не путать с
  другими версиями);
* `speakers` — список голосов. Для моделей серии v5.x голоса обычно те
  же самые (`aidar`, `baya`, `kseniya`, `xenia`, `eugene`) — но это стоит
  проверить: иногда новая модель добавляет новый голос или, наоборот,
  какого-то голоса в ней ещё нет (так было с `v5_4_ru`, где нет `eugene`).
  Если не уверен — начни с меньшего списка (`aidar`, `baya`, `kseniya`,
  `xenia`) и добавь остальных, если при озвучке они действительно
  работают.

Если хочешь, чтобы новая модель стала выбором по умолчанию, поменяй
строку чуть выше словаря:

```python
DEFAULT_SILERO_MODEL = "v5_5_ru"
```

на новый id.

### 4. Как проверить, что всё работает

Никакого отдельного шага для GUI не нужно — при следующем запуске
`fb2_reader.py`/`fb2_reader_gui.py` новая модель сама появится в
выпадающем списке «Модель», а голоса для неё — в списке «Голос».

Быстрая проверка из командной строки (без GUI), одна короткая глава:

```
python3 fb2_reader.py book.fb2 --mode silero --model v5_6_ru --speaker xenia --outdir test_out --start 1
```

Если модель скачается и первая глава озвучится без ошибок — всё подключено
верно. Модель качается один раз (файл `local_file` появится рядом со
скриптами) и дальше работает офлайн.

### Коротко (способ 2)

1. Открой models.yml по ссылке выше, найди новую запись `vN[_M]_ru` в
   разделе `ru:`.
2. Скопируй её `package`-ссылку.
3. Добавь новый блок в `SILERO_MODELS` в `silero_config.py` — id, title,
   package_url, local_file, speakers.
4. (не обязательно) обнови `DEFAULT_SILERO_MODEL`.
5. Перезапусти программу — модель появится в GUI сама.
