# Артефакты звука Silero (не ударения)

Жалоба с прослушивания вида «на 5:40 растягивает "ноооо там"» — НЕ ошибка ударения: модель Silero на коротком фрагменте выдаёт гул. Сначала локализовать, потом воспроизвести, потом чинить системно, а не по одному месту.

## Автопочинка по ASR — СДЕЛАНО (21.10.2026): `asr_autorepair.py` + `tools/asr_worker.py`, флаг `--asr-repair` / галочка GUI (по умолчанию вкл.)
Остались к решению: общий пересинтез книги (затронуты все 50 глав: эмоции в абзацах >700, словарь, гулы) — ПОСЛЕ прослушивания клипов `sample_book\_asr\clips\anomalies`.
- **Что за гул.** Silero синтезирует кусок ОДНОЙ последовательностью (`<break>` лишь растягивает пробел, темп покадровый); гул/«Н растягивается» — завышенная длительность начальной носовой «н/м» слова, ~0,4% кусков; детерминирован, но ХАОТИЧЕН по входу: ни одно свойство (пауза, слово, темп) не предсказывает его, поэтому работает схема «поймать и повторить», профилактики нет. Проверено: убрать паузу перед словом, темп −5 %, раздельный синтез предложения лечат; темп +5 %, строчная буква, ударение, укорочение паузы, слияние предложений — нет; ускорение одного слова — непредсказуемо.
- **Детектор** (`chunk_defects`): `hum` (слово «ммм/аммм/аааа…», которого нет в тексте), `stretch` (слово >2,5 с, кроме заголовка 1-го куска), `missing` (≥8 слов проглочено), `gap` (пауза между двумя узнанными словами дольше нормы для знака: ''0,35 / запятая 0,75 / предложение 0,95 / абзац 1,35 с; пороги — по 168 тыс. пауз 50 глав). НЕ ловит подмену слова («На то» → «Но-то»): такие ошибки неотличимы от ошибок Whisper на именах.
- **Лечение по порядку** (`tweaks_for`): убрать паузу перед словом → раздельный синтез повреждённого предложения (2 запроса + склейка `join_wavs`, это вылечило оба «неизлечимых») → темп −5 → без пауз на запятых → без `<prosody>` эмоции → … → вырезание гула из звука (`cut_spans`/`voiced_spans`), принимается только если ASR подтверждает улучшение. Исходный кусок остаётся, если лучше нет. Отчёт: `<outdir>\asr_repairs.jsonl` (с SSML).
- **Модель ASR.** `small` на отрезке куска нестабилен (гул иногда не пишет словом). Лучше `medium` (`~\.cache\whisper\medium.pt`, SHA-256 `345ae4da…`, пользователь скачал вручную: с сервера качается часами); `asr_worker.py` берёт `medium`, при отсутствии файла — `small` (никогда не качать на лету). Итог на гл. 28+36: проверено 82 куска, 4 дефекта, 4 исправлено; гулы 5:25 и 19:07 ушли, 3:55 (подмена «На то»→«Но-то») осталась.
- **Ограничения.** Recall ASR-детекции < 100 % (в одном прогоне пропущено 2 из 7 известных гулов, часть возвращается/уходит случайно при пересинтезе); возможный следующий шаг — второй проход по целой главе (Whisper на всей главе пишет гул словом стабильнее) с поиском куска по времени. Собранный .exe автопочинку не получает (воркер в `tools\`, окружение `.venv_cosyvoice3`).
- **Ловушка тулзов:** в heredoc через Bash-инструмент обратные слеши схлопываются (`\\x00` → NUL в файле, `\\s`) — Python-правки с `\` делать через Edit/Write, не через `python - <<EOF`.

## Что установлено (20–21 октября 2026)
- Место жалобы: глава 1, файл `002_Глава 1.wav`, 339,9–354 с, кусок №10 из 44 («К счастью, системы жизнеобеспечения…» … «пространства.»). ASR Whisper там выдаёт мусор («Курс-Ангел…», «Грортом»), слово на 14,5 с — артефакт таймстемпов; реальная растяжка секунды.
- **Воспроизведено**: фраза «курортом, но там, по крайней мере» между `<break>` читается «курортом? Ммм, на том». Детерминированно (4 прогона побитово равны, Silero на CPU). Мелкие правки пауз (убрать `<break>` после «курортом,» или после «там,») гул убирают — но это единичное наблюдение, общего правила нет. Прецедент в коде: `_DA_UZH_RE` («Да уж» → «Длож»).
- Звук из воспроизведения отличается от файла пользователя (0,6 с гула против секунд) — вход в боевом прогоне мог отличаться метками ударений.

## Как воспроизводить (ловушки)
- Бить в **`/getssmlwav`** с `raw_ssml=true` (как `run_silero_rest`), НЕ в `/getwav`: на `/getwav` теги `<break>` читаются вслух («сто двадцать»).
- Параметры как в мета-файле главы: `speaker xenia`, `sample_rate 48000`, `strip_mono true`, `server_accent false`; паузы 270/490/120 мс, `emphasize`, `max_len 700`.
- Кусок строить так же, как программа: `_split_paragraphs_for_ssml(текст_главы, 700)` → `apply_stress_dictionary_protected` → `apply_stress_layers` (с прайм-контекстом предыдущих кусков) → `latin_to_cyrillic_ru` → `text_to_ssml(...)`. Скрипт-образец был в scratchpad `repro.py` (не в репозитории).
- Сервис Silero: `.venv\Scripts\python.exe silero_rest_service.py` (порт 5010, `/health` нет — 404 означает «жив»). Остановить после работы (`netstat -ano | findstr :5010` → `taskkill /PID`).
- ASR одного файла: положить в временную папку как `001_x.wav` и запустить `tools\asr_cache_cuda.py <папка> 0`.

## Детектор (для ASR-скана)
Слово дольше 1,5 с; вставки-гулы («Ммм», «Ээ») между словами текста; провалы покрытия/CER кусков (`tools\chapter_asr_check.py`, флаг `resynth`); зацикливание (`loop_ratio`). Whisper-таймстемпы могут растягивать слово на паузу — сверять с текстом главы. ASR не проверяет ударения.
