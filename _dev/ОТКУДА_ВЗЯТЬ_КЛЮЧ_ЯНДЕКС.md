# Откуда брать ключи для Yandex SpeechKit (режим yandex)

Этот режим — облачный синтез речи от Яндекса. Он не бесплатный (после
пробного периода) и требует интернет на каждую главу, зато даёт
качественные голоса с интонацией. Ниже — как получить всё необходимое:
API-ключ и (по желанию) Folder ID.

Если платить за облако не хочется — локальный режим **Silero** в этой же
программе бесплатный, работает офлайн и теперь тоже расставляет паузы
по пунктуации, ничем принципиально не хуже. Yandex SpeechKit имеет смысл,
если вам нужны именно его голоса/интонации или уже есть аккаунт в
Yandex Cloud.

Яндекс в последнее время переносит управление ключами в новый интерфейс
**AI Studio** (`aistudio.yandex.ru`) — он проще классической консоли
Yandex Cloud и, похоже, сейчас основной способ быстро получить ключ.
Ниже — сначала этот, более короткий путь, а следом — старый способ через
IAM в консоли Yandex Cloud (тот же результат, просто на случай, если у
вас показывается другой интерфейс).

## Способ 1 (короче): через AI Studio

1. Откройте https://aistudio.yandex.ru и войдите под своим
   Яндекс-аккаунтом (или создайте его).
2. Если это первый заход — потребуется привязать платёжный аккаунт и
   активировать пробный период. Обычно даётся тестовый грант и/или
   бесплатный период на старте — точные условия смотрите прямо в
   интерфейсе, они время от времени меняются.
3. Откройте свой каталог (folder) — в интерфейсе он обычно выбран сразу
   после входа; его id виден в адресной строке браузера, в пути вида
   `/platform/folders/<folder id>/...` (например
   `b1g78pvcud4sv8qj3gs7`) — это и есть Folder ID, если он вдруг
   понадобится (для обычного сценария из этого README — не нужен).
4. Перейдите в раздел **"Доступ"** ("Access") этого каталога — прямая
   ссылка выглядит как
   `https://aistudio.yandex.ru/platform/folders/<folder id>/access`.
5. Там можно выпустить API-ключ для сервисного аккаунта (создать
   сервисный аккаунт, если его ещё нет, и сгенерировать для него
   ключ) — конкретные подписи кнопок могут немного отличаться от
   версии к версии интерфейса, но смысл раздела именно такой: доступ
   и ключи для этого каталога.
6. **Ключ показывается только один раз** в момент создания — сразу
   скопируйте его и сохраните в надёжном месте (менеджер паролей,
   защищённый файл).
7. Убедитесь, что у сервисного аккаунта, которому выпущен ключ, есть
   роль **`ai.speechkit-tts.user`** (доступ к синтезу речи) — без неё
   запросы будут падать с ошибкой 403. Роли аккаунта обычно смотрятся
   там же, в разделе "Доступ"/"Роли" каталога.

Это и есть значение для поля **«API-ключ»** в программе.

## Способ 2 (альтернативный): через классическую консоль Yandex Cloud

Если у вас показывается старый интерфейс или способ 1 не подошёл:

1. Откройте https://console.yandex.cloud — это официальная консоль
   управления Yandex Cloud.
2. Войдите под своим Яндекс-аккаунтом, при первом заходе привяжите
   платёжный аккаунт и активируйте пробный период (см. пункт 2 выше).
3. Выберите/создайте каталог (folder) — обычно один уже создан по
   умолчанию.
4. Откройте раздел **Identity and Access Management** (IAM) → слева
   **"Сервисные аккаунты"** → **"Создать сервисный аккаунт"**, дайте
   ему любое понятное имя (например `fb2-reader-tts`) и назначьте роль
   **`ai.speechkit-tts.user`**.
5. Откройте созданный сервисный аккаунт → **"Создать новый ключ"** →
   **"Создать API-ключ"** → при желании впишите описание → **"Создать"**.
6. Скопируйте ключ сразу — он показывается один раз.

## Вставить ключ в программу

В графическом интерфейсе — блок **«Yandex SpeechKit (режим yandex)»**
справа, поле «API-ключ». Поле «Folder ID» можно оставить пустым — оно не
нужно для ключа сервисного аккаунта (см. ниже почему).

Из командной строки:

```
python3 fb2_reader.py book.fb2 --mode yandex --yandex-api-key <ваш ключ> --yandex-voice alena --outdir audiobook
```

Ключ также можно один раз задать переменной окружения, чтобы не
вписывать каждый раз:

```
# Windows (cmd)
set YANDEX_API_KEY=ваш_ключ

# Windows (PowerShell)
$env:YANDEX_API_KEY = "ваш_ключ"
```

и запускать без флага `--yandex-api-key` — программа подхватит ключ из
переменной окружения `YANDEX_API_KEY` сама (то же самое для
`YANDEX_FOLDER_ID`, если он всё же понадобится).

## Про Folder ID — почему его можно не указывать

У Yandex SpeechKit два основных способа авторизации:

* **IAM-токен пользовательского аккаунта** — токен недолговечен (нужно
  периодически обновлять) и в запросе обязательно нужно передавать
  Folder ID отдельно.
* **API-ключ сервисного аккаунта** (то, что описано выше и что
  использует этот скрипт) — ключ долговечный, и SpeechKit сам понимает,
  в каком каталоге был создан аккаунт, выпустивший ключ. Folder ID в
  запросе можно не передавать вовсе.

Поле «Folder ID» в программе оставлено на случай, если вы всё же
захотите его указать (например, если один ключ почему-то должен слать
запросы от имени другого каталога) — в обычном сценарии оно не нужно.

## Частые проблемы

**403 / доступ запрещён** — сервисному аккаунту, выпустившему ключ, не
назначена роль `ai.speechkit-tts.user`, либо не активирован пробный
период/платёжный аккаунт (см. шаги выше).

**401 / неверный ключ** — проверьте, что ключ скопирован полностью,
без лишних пробелов и переносов строк, и что это именно API-ключ (а не,
например, OAuth-токен из другого раздела консоли).

**Голос за деньги закончился/лимит превышен** — SpeechKit платный после
пробного периода, оплата идёт по количеству символов в месяц. Проверьте
баланс и биллинг в консоли Yandex Cloud.
